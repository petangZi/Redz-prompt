## About

This repository contains collections of:
- jailbreak prompts
- policy puppetry experiments
- refusal suppression patterns
- persona injection prompts
- compliance drift tests
- context manipulation methods
- structured prompt formats
- behavioral mapping notes
- synthetic roleplay systems

Some are broken after updates.

---

## Focus Areas

### ⚡ Policy Puppetry
Structured prompts designed to simulate internal policies, configs, and authority layers.

### 🧠 Persona Injection
Behavior steering using fictional identities, simulation framing, and synthetic system roles.

### 💀 Compliance Drift
Experiments observing how models behave under layered context pressure.

### 🔥 Refusal Suppression
Research into refusal-trigger patterns, response shaping, and output redirection.

### 🌀 Context Manipulation
Testing how formatting, semantic framing, and hierarchy influence model behavior.
